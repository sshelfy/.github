# sshelfy

**A free, open-source SSH and SFTP client.**
Terminal, file transfers and an encrypted vault in one app. No telemetry.

### What it does

- **Hosts on a shelf:** nested groups, search, quick connect and import from `~/.ssh/config`.
- **Terminal in tabs:** truecolor, split panes with broadcast input, command palette, images in the terminal.
- **Files over SFTP:** two-panel mode, folder compare, editing in your own editor with automatic upload.
- **Connections:** jump hosts, port forwarding, SSH agent, certificates and FIDO2 security keys.
- **Secrets stay yours:** passwords and keys live in an encrypted vault (AES-256-GCM) behind a master password.
